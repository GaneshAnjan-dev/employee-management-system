# Employee Management System (Console, Java)

Simple file-based Employee Management System using Core Java and OOP.

## Features
- Add employee (id, name, department, salary)
- View all employees (sorted by ID)
- Search, update, delete employee
- Data stored in `employees.txt` for persistence

## How to Run
1. Create a Java project named `Employee Management System` in Eclipse.
2. Add package `ems` with `Employee`, `EmployeeService`, and `MainApp` classes.
3. Run `MainApp` (console menu).
